# Frontend mockups

This directory contains the complete interactive mockup suite for the patient portal and staff operations application described in `../ARCHITECTURE.txt` and `../API.txt`.

Open `index.html` in a browser, or serve this directory with any static web server. The prototype is intentionally dependency-free and uses only synthetic information.

## Included screens

- Authentication: sign in and access denied
- Patient portal: overview, appointments, health records, bills and payments, profile and proxy access
- Staff operations: work queue, patient registry, patient summary, demographics, encounters, medications, labs, patient billing, schedule, insurance, pharmacy, inventory, notifications, compliance cases, audit evidence, and reports
- Shared interaction states: loading, empty, stale, validation, denied, conflict, unavailable, confirmation, and success feedback

## Prototype controls

- Use **Portal view** and **Staff view** to change product surfaces.
- Use the staff role selector to preview role-filtered navigation.
- Use **All screens** to jump directly to any mockup route.
- Forms, tabs, filters, dialogs, the mobile navigation drawer, and representative workflow actions are interactive.

This is a visual and interaction reference, not an API-integrated implementation. It must not be connected to production patient data.
